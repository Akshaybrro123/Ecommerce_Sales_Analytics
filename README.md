# 🛒 E-Commerce Sales Analytics System

## 📌 Project Overview
The **E-Commerce Sales Analytics System** is a MySQL-based database project designed to manage and analyze e-commerce business operations. This project simulates a real-world e-commerce environment by storing and managing customer, product, category, order, and payment information.

The primary objective of this project is to demonstrate practical implementation of SQL concepts and perform business analytics using structured queries.

---

## 🚀 Features
- Customer Management
- Product and Category Management
- Order Processing
- Payment Tracking
- Sales Analytics
- Revenue Reporting
- Inventory Monitoring
- Business Intelligence Queries

---

## 🗂️ Database Tables
The project consists of the following relational tables:

- Customers
- Categories
- Products
- Orders
- Order_Details
- Payments
